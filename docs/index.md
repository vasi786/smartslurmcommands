# smartslurmcommands
A suite of smarter Bash wrappers for Slurm. Each tool is a standalone binary (e.g., `smartcancel`).

- [`ssc`](subcommands/ssc.md): version reporting and exact-revision self-updates.
- [`smartqueue`](subcommands/smartqueue.md): filtered or native queue inspection.
- [`smartcancel`](subcommands/smartcancel.md): safe filtered cancellation.
- [`mqpwd`](subcommands/mqpwd.md): directory-oriented queue inspection.
